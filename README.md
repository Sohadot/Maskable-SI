# Maskable.si — Maskable Superintelligence

An independent, future-facing concept study of **capability maskability** for advanced AI and superintelligence. The domain is the brand: **Maskable** + **.si** (Superintelligence).

## Status

This is a concept and strategic-positioning landing page with a browser-only capability-envelope simulator. It is **not** a deployed frontier-AI system, a working containment layer, an AI alignment solution, a certified solution, or a claim of operational control over superintelligence. No clients, integrations, market value, or approvals are claimed.

The simulator illustrates a predefined policy decision for six hypothetical capabilities. It does not execute any AI or tool, enforce real access controls, or substantiate that masking interfaces can constrain an advanced model's internal abilities. It makes no network requests, collects no data, and has no state persistence.

## Preview

Serve the project root via a static HTTP server, e.g. `python3 -m http.server 8080`, and open `http://localhost:8080`.

## Source hierarchy

- `index.html` — principal editorial and interactive landing page
- `assets/styles.css` — accessible responsive design
- `assets/app.js` — browser-only illustrative capability-envelope simulator
- `acquire/index.html` — separate, noindex strategic inquiries
- `tests/smoke.mjs` — structural and behavior tests
- `robots.txt`, `sitemap.xml` — homepage discovery, acquisition excluded

These references inform the concept but do not endorse it. The `.si` extension technically remains Slovenia's ccTLD in the DNS system; its **brand meaning** in this project is explicitly **Superintelligence**. Domain configuration and publication are separate from this repository work.
